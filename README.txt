BLUE KAPS SPORTS & EVENT — FULL WEBSITE FRONTEND

This version is a complete frontend website prototype designed to be hosted later.

Included:
- Home / brand website
- Ground Booking page
- 3 grounds
- Tennis + Leather slots and prices
- Practice / Tournament booking type
- Team name, captain name, mobile number
- WhatsApp payment-screenshot flow
- Available / Booked display
- Tournament Management page
- Services page
- Sports Shop Coming Soon page
- Contact page
- Responsive mobile design
- DK Admin Demo approval panel

IMPORTANT:
This version uses browser memory for booking requests. It is NOT yet a shared online backend.
Next we will connect the same UI to a free backend (Google Sheets + Apps Script or Supabase) so customer/admin devices share live data.

RUN:
npm install
npm run dev

BUILD:
npm run build
